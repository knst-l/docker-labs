# Docker Labs

Учебные проекты по Docker.

- `00-docker-hello` — локальная веб-страница с изображением.
- `01-zigzag-copy` — приложение Zigzag.
- `02-zigzag-repository` — сборка Zigzag из репозитория.
- `03-database-stack` — приложение с базой данных.

В репозитории размещена обычная версия проектов без учебной конфигурации прокси и без привязки к Alpine Linux.
